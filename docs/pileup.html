Region pile-up

The pile-up's own tables (regions and calls) come from seanome/2024-kmerseek-analysis at commit 39d81ec9 (results/leaderboard/pileup).

Where each tool's calls fall around a known domain. A call is a stretch of a human protein that a tool matched to a zebrafish protein carrying a Pfam domain. The call names that domain and spans the whole matched stretch, which can be much wider than the domain itself. Every row below is one region: one of the 2,435 Pfam domains on the 998 human query proteins. Every panel is one tool and setting searching the zebrafish proteome (zebrafish and human last shared an ancestor about 435 million years ago), and every panel has the same rows.

A residue counts as covered when a call naming that region's own Pfam family spans it, at any score the tool reported (E-value cutoff 10). Covered does not mean correctly placed: a call that runs far past the domain still covers it. Each row shows 100 residues before the region, then the region itself stretched or squeezed into 100 equal steps, then 100 residues after it, as deepTools does for genes. Each step shows the residue at its centre; the median region is 89 aa, so one step is about 0.9 aa.

Order rows by:

The order is set by one panel and used in all of them, so the rows line up across panels. In the other panels the same order can look like scattered stripes. Identity is the best pairwise identity between the human domain and any zebrafish domain of its family. Regions with no such domain, or no matching AlphaFold model, sort last.
