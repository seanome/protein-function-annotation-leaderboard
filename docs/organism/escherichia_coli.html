downloads this species' proteins and Swiss-Prot, runs nf-core/proteinannotator 1.1.0, then the three tools; needs a Unix computer with curl, Nextflow and Docker
# E. coli (Escherichia coli)
# UniProt reference proteome UP000000625, 4,403 proteins
curl -L -o proteome.fasta.gz 'https://rest.uniprot.org/uniprotkb/stream?query=proteome%3AUP000000625&format=fasta&compressed=true'
# All reviewed Swiss-Prot proteins, the source of the labels (they include those of the nearest reviewed relative, Escherichia fergusonii).
# Swiss-Prot has about 575,000 proteins; the board measured cost against one relative's proteome of about 20,000, so expect longer runs.
curl -L -o swissprot.fasta.gz 'https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/complete/uniprot_sprot.fasta.gz'
# nf-core/proteinannotator 1.1.0: Pfam, FunFam and InterProScan on your proteome.
# Version 1.1.0 has no option to run the tools below; their commands follow.
printf 'id,fasta\nescherichia_coli,proteome.fasta.gz\n' > samplesheet.csv
nextflow run nf-core/proteinannotator -r 1.1.0 -profile docker --input samplesheet.csv --outdir results
