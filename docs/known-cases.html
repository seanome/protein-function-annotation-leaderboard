Known cases

Fourteen pairs of proteins whose shared job was proven in a laboratory, and what each of the nine tools on this board does with them. This page shows illustrations, not rates. The rates stay in Table 1.

Data from 15 Oct 2026, commit 4a4b1171 (source)

Each case is one query protein searched against UniProtKB/Swiss-Prot release 2026_03. That is the opposite direction from Table 1, which searches human proteins against one relative's proteome.

Three words this page uses throughout. IoU (intersection over union) is the number of residues a call and the true region share, divided by the number either one covers. The site counts a call as correct at an IoU of 0.5 or more. An E-value is how many hits as good as this one a search of a database this size would be expected to turn up by chance, so smaller is better. A decoy is the same query with its residues reshuffled so that every pair of neighbouring residues still occurs as often as before. A hit counts only when the real query beats its decoy. Every query here has one decoy, shuffled with seed 1.

24 query proteins over 14 cases, each searched by 9 tools at the setting Table 1 calls that tool's best. None of these searches has been run yet. Each result lands in its own place on the cards below as the runs finish; until then every mark reads not run and says why.

The four boxes

Each case sits in one of four boxes, and the box decides what counts as a right call.

  1. Box 1. Shared ancestor, same job. The two proteins descend from one ancestral protein and still do the same job. A call is right when it names the target's family and transfers its function.
  2. Box 2. Shared ancestor, new job. The two proteins descend from one ancestral protein, but the query protein has taken on a different job. A call is right when it names the family, and wrong when it carries the target's function across.
  3. Box 3. No shared ancestor, whole protein. The two proteins reached the same job from different ancestors, so there is no family truth. A call that names the target's family is wrong by ancestry and right by function, and the card shows both marks.
  4. Box 4. No shared ancestor, short motif. A short stretch of the query protein copies a short stretch of a human protein. A call is right when it lands on those residues.

Which tool finds which case

found: a call on the right target protein that overlaps the true region with an IoU of 0.5 or morewrong place: a call on the right target protein, but its overlap with the true region is an IoU below 0.5wrong label: the call carries the human protein's job across to a protein that does not do that jobmissed: no call on that protein above the tool's own cutoffnot run: the search has not been run; each card says why

What a search costs

The cost on every card is core-hours × the price of a core-hour, plus GPU-hours × the price of a GPU-hour, the same arithmetic the cost page uses. Until a case has been run, the core-hours are the ones the Table 1 run measured for that tool against one relative's proteome. Swiss-Prot is larger than any one proteome, so those numbers are a floor.
