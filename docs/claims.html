Claims

What each tool's authors claim, the result that would disprove each claim, and where it stands. 5 tools have claims here. The claims for DIAMOND, Foldseek, phmmer (HMMER 3), MMseqs2 quote the authors' own paper, README or website, with the link; kmerseek's are ours.

● holds: its test ran and did not disprove it ○ not yet tested: the test has not run, or the data cannot decide it ⊘ disproved: the test disproved it

The build recomputes every verdict from the tables or checks it against the recorded notebook output, so nothing on a card is typed in by hand.

      The authors' words: “Foldseek enables fast and sensitive comparisons of large protein structure sets” (github.com/steineggerlab/foldseek, fetched 16 Oct 2026)
