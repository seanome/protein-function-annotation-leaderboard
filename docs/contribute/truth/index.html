Add a region your lab has tested

One protein region per form, with what your experiment showed about it. It goes to a public curation queue. Once accepted, every tool on the leaderboard is graded on it at the next rebuild of the tables, if the protein is in one of the query sets (the fixed lists of proteins the tools are run on); otherwise it is kept and counted for its organism until a query set includes it.

Data from 15 Oct 2026, commit 4a4b1171 (source)

How the form reaches GitHub

This site is a set of static pages with no server, so it cannot store anything. The button at the end opens GitHub's new-issue page for seanome/protein-function-annotation-leaderboard with your answers already written in. You read them there and press Submit new issue. That needs a free GitHub account, and the issue is public. The curator answers in the same issue.

Protein

Give the UniProt accession, or, only if there is none, the sequence and the organism.

Region

Required. Residue positions on that sequence, counting the first residue as 1. Both ends are part of the region. If your experiment used another isoform or an older sequence, convert the positions to the UniProt sequence first.
