Contribute

The leaderboard grows in two ways without anyone here running your tool or your experiment. Tool authors send predictions; labs send regions they have tested.

Data from 15 Oct 2026, commit 4a4b1171 (source)

Tool authors: send predictions

Run your tool on one of the fixed query sets in data/query_sets/, then open a pull request that adds one folder under submissions/ with three files: the predictions, a timing log, and a short tool card. A workflow grades the predictions with the same scorer that made every number on this site and posts the rows on the pull request. Cost numbers you send are shown as reported, with your hardware named, never as measured. CONTRIBUTING.md has the five steps and a worked example with MMseqs2. The leaderboard table does not show submitted rows yet; until it does, they are on the pull request and in the repository.

Labs: send a region you have tested

If your lab has shown by experiment that a stretch of a protein binds something, carries an activity, sends the protein somewhere in the cell, or has a solved structure, that region is a test every tool can be graded on. The form takes one region at a time. A curator checks it against the rules in docs/curation.md; a row that only repeats an annotation already in a database is turned down, because the tools are already graded on those.
