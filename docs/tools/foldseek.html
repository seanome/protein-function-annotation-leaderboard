Foldseek

Tool id foldseek. Numbers from seanome/2024-kmerseek-analysis commit 7eca428b.

What it compares

Predicted 3-D shapes. Each residue of an AlphaFold model gets one of 20 shape letters (3Di) from its local fold. The shape letters are aligned together with the amino acids.

What it needs

  • sequence only: no
  • 3D structure prediction: yes
  • GPU: no

Reference searched

AlphaFold models of the relative's proteome (Quest for Orthologs reference proteomes, release 2020_04 accessions), as a Foldseek database.

How to read its score

Bit score: higher ranks first. The E-value cutoff was 10.

Strong and weak strata

Under the Pfam truth set, raw calls, zebrafish (435 Mya) as the relative searched, its best setting is 3di_aa: Fmax 0.250 over 2,435 true instances. Below, each stratum compares this setting with the best setting of any other tool in that same stratum, so the other tool's setting can change from line to line. Only strata with at least 30 true instances are compared.

Where it is closest to, or furthest ahead of, the best other tool:

  • no same-family domain in the relative: Fmax 0.027 (n = 321); best other: HH-suite (hhsearch) single_seq, 0.032.
  • identity 30–40% to the closest same-family domain: Fmax 0.167 (n = 165); best other: MMseqs2, three rounds s7, 0.209.

Where it is furthest behind the best other tool:

  • regions 16–30 aa long: Fmax 0.004 (n = 271); best other: kmerseek wwmj5_k11_lcFalse, 0.330.
  • regions 31–60 aa long: Fmax 0.034 (n = 420); best other: kmerseek gbmr4_k21_lcFalse, 0.232.

Swiss-Prot features, raw calls, zebrafish, setting 3di_aa: best feature type ACT_SITE (active site residue), Fmax 0.285 (n = 176); worst TRANSMEM (membrane-spanning segment), Fmax 0.000 (n = 1,124).

Known failure modes

  • A protein with no AlphaFold model cannot be searched. Five relatives have no Foldseek rows at all (chimpanzee, cow, dog, opossum, western clawed frog): not run.
  • AlphaFold models of long proteins come in overlapping pieces (F1, F2, ...). The task script moves piece n's coordinates 200 x (n - 1) residues along the protein; if a piece started elsewhere, its calls would land in the wrong place. Checked against the real piece starts: not measured.

Cost per 1,000 queries

Setting 3di_aa, searching one relative (mean over the 10 relatives it searched): 0.129 core-hours reserved per 1,000 queries (16 cores for the task's wall time), measured on Sherlock. Peak memory 1.5 GB. That is about $0.00574 at $0.044625 per CPU-hour. Building its databases took 0.267 core-hours over 2 databases. A database is built once and reused, so this is not in the per-query cost.

The per-query cost counts the search only. The run recorded cost per tool and setting, summed over all relatives, so the cost for one relative is the mean.

Hardware

Hardware of the search (setting 3di_aa, every task): Sherlock partition hns, from the trace. Host name: not recorded in the trace, so the node is the one SLURM's job record (sacct) gives. 10 tasks on 9 nodes. CPU: AMD 7763 (3 tasks); AMD 8224P (3 tasks); AMD 7742 (2 tasks); AMD 7543 (1 task); AMD 9754 (1 task). GPU: none allocated.

Hardware of the database build: Sherlock partition hns, from the trace. Host name: not recorded in the trace, so the node is the one SLURM's job record (sacct) gives. 2 tasks on 2 nodes. CPU: AMD 7742 (1 task); not recorded, as scontrol no longer finds the node (1 task). GPU: none allocated.

Sources, read 2026-10-16: the partition is the queue column of the run's Nextflow traces. The traces have no hostname column, so the node is the one SLURM's job record (sacct) gives for the trace's job id. CPU and GPU are that node's features in SLURM (scontrol show node: CPU_MNF, CPU_SKU, GPU_SKU), named as on Sherlock's node features page. Partition hns is owned by a research group, and Sherlock's tech specs page lists no CPU models for such partitions. Script: scripts/read_hardware.py.

Will it work for you?

  1. Is the closest same-family domain in the relative you will search at least 40% identical, for most of your proteins? If yes, Fmax here is 40–60% 0.164 (n = 563), 60–100% 0.241 (n = 1,289). If no, 20–30% 0.268 (n = 93), 30–40% 0.167 (n = 165). (Pfam truth set, raw calls, zebrafish (435 Mya) as the relative searched, setting 3di_aa; strata with at least 30 true instances.)
  2. Do you have a 3D structure prediction for every protein you want to annotate? If not, Foldseek cannot search the proteins without one.
  3. Can you spend about 0.129 core-hours per 1,000 proteins for each relative you search? That is the measured mean per relative; see "Cost per 1,000 queries" above.
